THE HOUSE OF HOPE FOUNDATION — WEBSITE PACKAGE

FILES
- index.html: responsive one-page website with an interactive donation checkout preview.
- assets/hero-gaza.jpg: hero background image. Keep this folder beside index.html.

OPENING THE WEBSITE
1. Extract the ZIP archive.
2. Keep the assets folder in the same directory as index.html.
3. Open index.html in a modern browser, or upload the complete folder to your web host.

DONATION CHECKOUT PREVIEW
The donation form supports USD, EUR and GBP display, one-time/monthly selection, preset/custom amounts, donor details and an interactive Visa/Mastercard checkout preview. The checkout preview displays a sample masked card and a simulated receipt. It does not request or transmit real card details, charge a card, create a real payment, convert funds or transfer Bitcoin.

LIVE PAYMENT REQUIREMENTS
To accept real donations, connect an eligible payment processor using its hosted checkout and server-side API. Confirm that the provider supports the Foundation's country, charity status, card currencies, conversion and BTC settlement. Store API credentials on the server, verify signed payment webhooks, and only issue real receipts after confirmed payment. Do not collect or store card numbers or CVC in this static website. Confirm wallet ownership independently before enabling settlement.
